# Российские сервисы напрямую через AmneziaVPN

Один файл для **iPhone / iPad, Android, Windows и macOS**.

[Скачать amnezia-ru-direct-ip.json](https://raw.githubusercontent.com/matvel58/Amnezia-ru-direct/main/amnezia-ru-direct-ip.json)

## Установка

1. Скачайте файл по ссылке выше.
2. Отключите VPN и откройте AmneziaVPN.
3. Перейдите в **Настройки → Раздельное туннелирование сайтов**.
4. Включите функцию и выберите **«Напрямую»**.
5. Нажмите **⋮ → Заменить список с сайтами** и выберите скачанный JSON-файл.
6. Подключите VPN заново.

На iPhone / iPad, если Safari показывает текст JSON, нажмите **«Поделиться» → «Сохранить в Файлы»**, затем выберите сохранённый файл в Amnezia.

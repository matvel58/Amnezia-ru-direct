Настройка прямого доступа к Российским сервисам через Amnezia VPN

* Скачайте файл amnezia-ru-direct-ip.json.
* Откройте Amnezia VPN.
* Перейдите в Настройки → Раздельное туннелирование сайтов.
* Включите переключатель «Раздельное туннелирование сайтов».
* Выберите «Напрямую».
* Нажмите ⋮ в правом нижнем углу.
* Выберите «Заменить список с сайтами».
* Укажите скачанный JSON-файл.

Готово! РУ сервисы будут открываться напрямую, остальные — через VPN.
